# Phase 0 research memo — silent-trials

This memo is generated by `research/phase0/render_docs.py` from harness
`results.json` files. Narrative is the template; every quantitative claim is
substituted from those files. Re-run `make research` after changing a harness.

**Safety.** This project is research / decision-support tooling. It is not a
regulatory determination of FDAAA 801 compliance, not a medical device, and
not clinical advice. Phase 0 uses designed synthetic records modeled on
ClinicalTrials.gov and PubMed. No live registry dump is committed or queried.

---

## §1 Problem statement

A large share of interventional psychiatry and neurology trials finish,
disappear from the results module, and never become a paper. Sponsors still
cite "the evidence" as if the missing cells were noise. Patients, payers, and
guideline writers inherit a literature that is a filtered sample of what was
registered.

The obvious fix — "download ClinicalTrials.gov and grep PubMed for the NCT" —
fails in the typical psychiatry paper, which still omits the identifier, and
it fails in the other direction when a late review by the same PI is treated
as the trial report. A time-unaware clock also invents silence: a trial that
completed three months ago is not late under the 12-month FDAAA window.

This repo builds an explainable linker and a time-aware FDAAA clock so
non-reporting can be counted by sponsor without silently converting matcher
error into a moral ranking.

## §2 Prior art

| Tool | What it does | Gap |
| --- | --- | --- |
| [ClinicalTrials.gov](https://clinicaltrials.gov/) results module | Registry results posting | Does not search journals; "no results" ≠ silent |
| [FDAAA TrialsTracker](https://fdaaa.trialstracker.net/) (Powell-Smith / Goldacre) | Public ACT due/overdue dashboard | Drug/device ACTs; not a neuro/psych publication linker |
| [TrialsTracker](https://trialstracker.net/) / [EU Trials Tracker](https://eu.trialstracker.net/) | Sponsor-level non-reporting | Different statute; publication matching is coarse |
| [WHO ICTRP](https://trialsearch.who.int/) | Cross-registry search | No publication reconciliation |
| [PubMed / NCT search](https://pubmed.ncbi.nlm.nih.gov/) | Identifier lookup | Misses papers that never print the NCT |
| [Cochrane / TRIP](https://www.cochranelibrary.com/) | Evidence synthesis | Assume the corpus; do not measure linker error |
| [OpenTrials](https://opentrials.net/) | Linked trial objects | Project inactive; linkage not an evaluated matcher |

Something already "solves" overdue ACTs: the FDAAA TrialsTracker does, at the
registry-results layer. Another engine is still worth building because
(1) a journal article is reporting even when the results module is empty,
(2) most psychiatry papers still omit the NCT, so identifier search is a
lower bound, and (3) the unmatched bucket is a mixture of true silence and
matcher misses — that mixture is the claim this repo measures first.

### 4.4 Clock and storage

Options for the clock: ignore dates; use study completion; use primary
completion plus 12 months, time-aware to a committed reference date.

Criterion: a trial that completed three months before 2026-10-06 must be
NOT_YET_DUE. Registry results without a journal article must be
REPORTED_REGISTRY, not silent.

Measurement: `tests/unit/test_fdaaa.py` (S3, S4, S10). Not a live FDA
enforcement sample — that sample is **unmeasured**.

Decision: **primary completion + 12 months, reference date 2026-10-06,
applicable-trial flag is a committed field.** Certified delays are
**unmeasured**.

Options for storage: JSONL of outcomes; DuckDB; a live warehouse.

Criterion: local, queryable, no service. DuckDB is the repo convention.

Decision: **DuckDB for batch sponsor tables in Phase 3.** Phase 0 writes
JSON + Markdown. DuckDB vs a live AACT replica scan is **unmeasured**.

## §5 Evaluation design

Hold-out (Phase 3, not run here): a pinned AACT snapshot plus a PubMed
snapshot, with hand-linked gold for a neuro/psych ACT slice.

Metrics, declared before any live pull:

- MATCH precision, recall, and F1 of the explainable matcher
- Decision accuracy across MATCH / NO_MATCH / AMBIGUOUS
- Recall per candidate-generation strategy
- Genuinely-unreported vs reported-but-unmatched among unmatched trials
- Sponsor-level silent rate on the live slice, with a sensitivity band
  from the unmatched split
- Baseline: NCT-only linker
- Second baseline: treat unmatched as silent

Split: pinned, committed snapshot dates. Seed 0. No random reshuffle in CI.

**Failure condition (written before the answer):** the project fails if, on
the live hold-out, MATCH precision is below 0.85 **or** MATCH recall is
below 0.80 **or** the unmatched split is not reported next to every
sponsor rank **or** any NOT_YET_DUE trial is emitted as SILENT.

## §7 Risks

| Risk | Type | Mitigation or acceptance |
| --- | --- | --- |
| Probe-set gold is designed, not live-linked | Data | Accepted for Phase 0. Memo and harness READMEs say so. Phase 3 replaces the 200. |
| Unmatched split is the largest error source | Technical | Measured ({{US_MISSED_FRAC}} reported-but-unmatched). Every later sponsor table must carry this band. |
| NCT-only search looks precise and is incomplete | Technical | Measured in candidate_recall. Combined generation is the default. |
| Time-unaware clock invents silence | Technical | Reference date committed. Tests cover 3-month and 4-month completions. |
| Registry results ignored, journal demanded | Scope | S4 is REPORTED_REGISTRY. Journal absence is not silence. |
| Output read as an FDA enforcement list | Legal | Disclaimer on CLI, README, memo. Not a determination. |
| Sponsor ranking on designed data | Scope | Forbidden. Demo cases are not a leaderboard. |
| Author-name variation / PI change | Data | Hard positives use a clean last name. Live transliteration is unmeasured. |
| Certified delay / good-cause extension | Legal | Unmeasured. Clock will over-call SILENT on delayed ACTs until ingested. |
